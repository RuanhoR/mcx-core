# MCX CONTRIBUTING.md
## English

### Guide
First, clone the repository and install dependencies
```bash
git clone https://github.com/RuanhoR/mcx-core.git
# It is recommended to use pnpm
pnpm i
```
Fork the repository on Github, and add it to your local git remote. Then write your code and commit it.
Note: `git commits must follow commit standards`
Before committing, please run
```bash
pnpm check
```
to perform checks and test the features you have updated. Finally, create a PR and wait for it to be merged.
