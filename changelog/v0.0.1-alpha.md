# v0.0.1-alpha (2026-02-05 — 2026-04-11)

Initial development phase. The MCX compiler was originally part of the mbler monorepo, then extracted to its own repository with three packages: `@mbler/mcx-core` (compiler), `@mbler/mcx-types` (type declarations), and `@mbler/mcx-client` (runtime framework).

### Features

- **MCX DSL Parsing**: Lexer and Parser for `.mcx` files; AST generation with optional comment inclusion
- **Rollup integration**: Custom Rollup plugin for building MCX projects; sourcemap support via `magic-string`
- **Transform system**:
  - App (`<App>`) and Event (`<Event>`) component transformation
  - UI component transformation (`<UI>`, `<form>`, `<toggle>`, etc.)
  - `tick` and `extends` prop support for Event components
  - `{{ prop }}` content binding syntax for UI components
  - `sfc_main` function generation for UI entry points
- **Module resolution**: Import resolution for MCX files; error handling for module lookup
- **Script extraction**: `compileMCXFn` for extracting embedded TypeScript from `.mcx` files
- **Runtime framework** (`@mbler/mcx-client`):
  - `Event` class (refactored from factory pattern to standard class)
  - `App` class for application mounting and event loading
  - `Utils` utility library with debounce (`generateAntiShake`)
- **TypeScript declarations** (`@mbler/mcx-types`): Type definitions for MCX projects
- **Volar language plugin**: `createMCXLanguagePlugin` factory for IDE support
- **Component system**: Base item/entity component JSON generation framework

### Fixes
