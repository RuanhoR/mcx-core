# v0.0.1 (2026-04-11 — 2026-05-25)

First tagged release. Focus on monorepo setup, component system expansion, and release preparation.

### Features

- **Monorepo restructure**: Assembled via `git subtree` from three previously independent repositories — `packages/core` (original MCX compiler), `packages/types` (type declarations), and `packages/client` (runtime framework) — unified under workspace protocol
- **ESLint + Contributing**: Added shareable ESLint config, verify-commit script, and CONTRIBUTING.md
- **Package resolver**: Custom module resolution for `@mbler/*` packages
- **Generic type inference**: Auto-deduce `run` parameter types using TypeScript generics
- **Compile cache**: Incremental compilation cache for faster rebuilds
- **Item component system**:
  - Base JSON structure generation with type checks
  - `setIcon` with hex string overload (auto-copies PNG resource to behavior pack)
  - `getXXX` accessor methods for all item properties
- **Entity component system**: JSON generation for entity components (preferred_path, addrider, etc.)
- **UI component library**: Form generation, interaction logic, export support
- **Hex icon resource handling**: Copy PNG icon resources using hex texture IDs
- **create-mbler support**: Template package for project scaffolding
- **Rolldown support**: Plugin exports adapted for Rolldown bundler
- **README**: Full documentation with usage examples
