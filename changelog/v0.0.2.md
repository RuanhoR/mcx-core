# v0.0.2 (2026-05-25 — 2026-07-26)

Performance optimization, source structure refactoring, and mcx-component rewrite with typed lazy class loading.

### Features

- **mcx-component lazy class loading**: New `createLazyClass<T>()` utility enables named imports with deferred module loading via Proxy — components are only instantiated when `new` is called
- **mcx-component typed exports**: `ItemComponent`, `BlockComponent`, `EntityComponent`, `RecipeComponent` exported as named exports with full type preservation through generic type parameters

### Performance

- **Eliminate double AST traversal**: Removed redundant `CompileJS.run()` call in `compileJSFn` (`compileJS.ts`)
- **`fs.access` instead of `fs.readFile`**: File existence checks no longer read entire file contents (`resolve.ts`)
- **Compiler caches `Record` → `Map`**: `compileJSFn.cache` and `compileMCXFn.cache` use `Map` for O(1) lookup; caches cleared between builds via `clearCompileCaches()` (`compileJS.ts`, `compileMCX.ts`, `main.ts`)
- **Precomputed attribute sets**: `generateLayout` precomputes combined `COMMON_ATTRS ∪ TAG_ATTRS` per tag instead of creating new `Set` per element (`layout.ts`)
- **Binary search for line-column**: `absOffsetToMCXPos` builds line-offset index once and uses binary search (`tag.ts`)
- **O(n) build cache**: `writeBuildCache` uses `Map` instead of nested linear scans (`compileJS.ts`)
- **Conditional `MagicString`**: sourcemap object only created when `opt.sourcemap` is true (`main.ts`)
- **Array push instead of spread**: `cachedOption` append uses `.push()` (`fileEdit.ts`)
- **`for...in` instead of `Object.getOwnPropertyNames`**: avoids array allocation (`main.ts`)

### Refactors

- **`compile-mcx/compiler/index.ts`** (561 lines) → `compileJS.ts` + `compileMCX.ts` + `index.ts`
- **`transforms/utils.ts`** (401 lines) → `ast-utils.ts` + `enable.ts` + `prop.ts` + `hooks.ts` + `utils.ts`
- **`mcx-component/index.ts`** (492 lines) → `fileEdit.ts` + `importScan.ts` + `texture.ts` + `cache.ts` + `index.ts`

- **ImageComponent**: Added `statSync()` file existence check before extension validation
