## 紹介
MCXはMCBEアドオンのDSLです。公式mcbeとは関係ありません。MCBEアドオンを簡単な方法で構築できます。

## 特徴
- コンポーネント: MCXはmcbeコンポーネントJSONを迅速に生成できます
- UI: MCXはUIを簡単に構築できます
- アプリ: MCXはこれらの機能を使用できます
- MCXクライアント: アプリを実行できます
- MCXコンパイラコアと[mbler](https://github.com/RuanhoR/mbler): アプリをビルドできます
- I18nをサポートしています
