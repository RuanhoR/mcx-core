## 소개
MCX는 MCBE 애드온 DSL입니다. 공식 mcbe와 관련이 없습니다. MCBE 애드온을 간단한 방법으로 만들 수 있게 해줍니다.

## 기능
- 컴포넌트: MCX는 mcbe 컴포넌트 JSON을 빠르게 생성할 수 있습니다
- UI: MCX는 UI를 간단하게 구축할 수 있습니다
- 앱: MCX는 이러한 기능을 사용할 수 있게 해줍니다
- MCX 클라이언트: 앱을 실행할 수 있게 해줍니다
- MCX 컴파일러 코어와 [mbler](https://github.com/RuanhoR/mbler): 앱을 빌드할 수 있게 해줍니다
- I18n을 지원합니다
