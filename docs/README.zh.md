## 介绍
MCX是MCBE附加组件的DSL。它与官方mcbe无关。它可以让你以简单的方式构建mcbe附加组件。

## 功能
- 组件: MCX可以快速生成mcbe组件JSON
- UI: MCX可以简单地构建UI
- 应用: MCX可以让你使用这些功能
- MCX客户端可以让你运行你的应用
- MCX编译器核心和[mbler](https://github.com/RuanhoR/mbler)可以让你构建应用
- 支持I18n
